A Christian platform for managing dioceses, parishes and churches, with a multilingual interface and dashboards to track community activity. The project includes real-data import pipelines for several Quebec dioceses, built with preflight checks and a rollback plan, along with an automated test suite (Vitest, Playwright) and continuous integration.
