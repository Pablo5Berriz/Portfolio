Application mobile pour cyclistes (React Native/Expo), avec planification de parcours, météo contextuelle et signalements communautaires. Architecture organisée par domaines fonctionnels (trajets, météo, signalements, favoris) avec Supabase en backend. Pas encore publiée sur les stores ; le dépôt compte 27 commits, une suite de tests Jest et un pipeline d'intégration continue.
